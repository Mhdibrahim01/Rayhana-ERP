# Rayhana ERP (نظام ريحانة لإدارة الفنادق والشقق المفندقية)

نظام إدارة فندقي متكامل مبني بتقنيات الويب الحديثة وبيئة Electron لسطح المكتب، موجه لإدارة الفنادق والشقق المفروشة مع واجهة عربية متكاملة (RTL) وتجربة مستخدم سريعة ودقيقة.

---

## ⚡ دليل استخدام لوحة الأوامر الذكية والبحث السريع (Ctrl + K)

تُعد **لوحة الأوامر الذكية (Smart Command Palette)** العصب الرئيسي للتنقل والتشغيل السريع في نظام ريحانة؛ حيث تتيح لموظف الاستقبال ومدير النظام الوصول لأي غرفة، حجز، نزيل، فاتورة، أو تقرير مالي وإداري خلال ثوانٍ معدودة مباشرة من لوحة المفاتيح دون الحاجة للمس الفأرة.

### 1. فتح وإغلاق لوحة الأوامر
- **اختصار لوحة المفاتيح:** اضغط <kbd>Ctrl</kbd> + <kbd>K</kbd> (أو <kbd>Cmd</kbd> + <kbd>K</kbd> على macOS) من أي شاشة داخل النظام.
- **الشريط العلوي (Topbar):** النقر على زر **لوحة الأوامر** بجانب شريط البحث العلوي.
- **التنقل والاختيار:**
  - الأسهم <kbd>↑</kbd> و <kbd>↓</kbd> للتنقل بين النتائج والأوامر.
  - مفتاح <kbd>Enter</kbd> لتنفيذ الأمر أو فتح السجل المحدد.
  - مفتاح <kbd>Tab</kbd> أو <kbd>Enter</kbd> للإكمال التلقائي عند كتابة بادئة أمر.
  - مفتاح <kbd>Esc</kbd> لإغلاق اللوحة فوراً.

---

### 2. رموز الوصول الفوري السريع (Prefix Shortcuts)

ابدأ نص البحث بأحد الرموز المخصصة للوصول الدقيق والمباشر:

| الرمز | المعنى والوظيفة | الصيغة | أمثلة تطبيقية | النتيجة والإجراء |
| :---: | :--- | :--- | :--- | :--- |
| **`#`** | **استعلام الحجز والعقد** | `# [رقم الحجز]` | `#105`<br>`# 1024` | يفتح تفاصيل الحجز فوراً مع أزرار سريعة لعرض الفاتورة، إضافة سند قبض، أو استعراض العقد. |
| **`@`** | **سجل النزلاء والحجز السريع** | `@ [اسم / جوال / هوية]` | `@محمد`<br>`@0500123456`<br>`@1088765432` | يبحث في قاعدة بيانات النزلاء. يوفر زر **«إنشاء حجز لهذا النزيل»** لتعبئة بياناته تلقائياً في شاشة التسكين، ويُظهر تحذيراً أحمر في حال كان النزيل في القائمة المحظورة (Blacklist). |
| **`!`** أو **`ق`** أو **`r`** | **استعلام حالة الغرفة** | `! [رقم الغرفة]`<br>`ق [رقم الغرفة]`<br>`r[رقم الغرفة]` | `!204`<br>`ق101`<br>`r305` | يفتح بطاقة تفاصيل الغرفة، النزيل الحالي، الرصيد المالي المتبقي، وأزرار مباشرة (فاتورة / سند قبض / تمديد / واتساب). |

---

### 3. الأوامر التشغيلية السريعة مع أرقام الغرف (مرونة الترتيب)

يدعم النظام الصياغة اللغوية الحرة؛ حيث يمكنك كتابة رقم الغرفة **قبل الكلمة أو بعدها**، بمسافة أو بدون مسافة:

- **🧾 الفواتير الضريبية:**
  - `فاتورة 205` أو `205 فاتورة` ← فتح الفاتورة الضريبية للغرفة فوراً للطباعة أو المعاينة.
- **💵 سندات القبض والدفعات:**
  - `سند 103` أو `103 سند` أو `قبض 103` أو `قبض103` ← فتح نافذة إضافة سند قبض مالي للغرفة.
- **🛏️ التسكين والحجز المباشر:**
  - `تسكين 101` أو `101 تسكين` أو `حجز 101` ← فتح نافذة إنشاء حجز وتسكين للغرفة المحددة.
- **⏱️ تمديد الإقامة:**
  - `تمديد 204` أو `204 تمديد` ← فتح شاشة تمديد الإقامة وتحديث عقد النزيل.
- **💬 مراسلة واتساب:**
  - `واتساب 204` أو `204 واتساب` ← فتح محادثة واتساب فورية مع النزيل برسالة ترحيبية وملخص الحجز.
- **🔍 استعلام سريع عن غرفة:**
  - `204` أو `مين في 204` أو `غرفة 204` ← عرض بطاقة الغرفة، حالة النظافة، النزيل المقيم، والرصيد المتبقي.

---

### 4. الأوامر الإدارية والتقارير الفورية (أوامر بكلمة واحدة)

أوامر مباشرة بدون أرقام تنقلك لأهم التقارير الرقابية والمالية:

- **📊 تقرير الوردية والدرج المالي:**
  - الكلمات المفتاحية: `وردية`، `درج`، `كاش`، `فلوس الدرج`، `صندوق`
  - الإجراء: فتح شاشة جرد الوردية الحالية والسيولة النقدية والمصروفات.
- **🚨 المستحقات والديون غير المدفوعة:**
  - الكلمات المفتاحية: `ديون`، `مستحق`، `غير مدفوع`، `مين عليه فلوس`، `باقي`
  - الإجراء: حصر النزلاء الذين عليهم مبالغ مستحقة مع ترتيبهم حسب الأولوية وزر دفع سريع لكل نزيل.
- **🚪 المغادرات اليومية والمتأخرون:**
  - الكلمات المفتاحية: `مغادرات`، `خروج اليوم`، `مين خارج اليوم`، `متأخرين`، `تأخير`
  - الإجراء: عرض نزلاء اليوم لمتابعة تسوية الخروج أو التمديد، وحصر المتأخرين عن وقت المغادرة.
- **🧹 تصفية الغرف بحسب الحالة:**
  - `متاح`، `فاضية`، `شاغر` ← تصفية الواجهة للغرف الجاهزة للتسكين.
  - `مشغول`، `ساكن` ← تصفية الواجهة للغرف المشغولة.
  - `تنظيف`، `نظافة` ← تصفية الواجهة للغرف التي تحت التجهيز.
- **🏢 تصفية الطوابق:**
  - `طابق 1`، `الدور 2`، `طابق 3`...
- **⛔ القائمة السوداء والنزلاء المحظورين:**
  - `محظورين`، `بلاك ليست`، `ممنوعين` ← فتح وإدارة سجل النزلاء المحظورين.
- **💾 النسخ الاحتياطي لقاعدة البيانات:**
  - `نسخ احتياطي`، `باك اب`، `حفظ نسخة` ← فتح شاشة النسخ الاحتياطي اليدوي والتلقائي.

### 5. المزايا الذكية في لوحة الأوامر

#### ⚡ الإكمال التلقائي للبادئات (Prefix Autocompletion)
- اكتب أول حرفين أو ثلاثة من أي أمر (مثل `فا`، `تسك`، `ور`، `ديو`).
- ستظهر بطاقات «أوامر مقترحة» أعلى القائمة مرتبة بالأولوية.
- اضغط <kbd>Tab</kbd> أو <kbd>Enter</kbd> لتكملة الكلمة تلقائياً مع مسافة، أو لتنفيذ الأمر المباشر فوراً.

#### 🛡️ مقاومة الأخطاء المطبعية والإملائية (Typo Resilience)
- يتعامل المحرك بذكاء مع الأخطاء الشائعة والسرعة في الكتابة (مثل `تسيكن 101` ← `تسكين 101`، `فتوره` ← `فاتورة`، `تدميد` ← `تمديد`).
- يتعرف النظام تلقائياً على الأمر المقصود عبر خوارزميات المسافة اللغوية والصوتية وينفذ المطلوب، مع إظهار شريط تنبيه يُتيح لك البحث عن النص الأصلي كاسم نزيل بنقرة واحدة.

#### 🌐 التحويل التلقائي للغة لوحة المفاتيح (Keyboard Layout Auto-Conversion)
- إذا نسيت لغة لوحة المفاتيح على الإنجليزية وكتبت أمراً عربياً (مثل `thj,vi 205` أو `js;dk 101`)، يقوم النظام بتحويل الحروف تلقائياً إلى العربية وتنفيذ الأمر فوراً دون الحاجة لإعادة كتابته.

## 🛠️ التشغيل والتطوير (Development)

- **بيئة التشغيل:** Node.js + Electron
- **الملفات الأساسية:**
  - `dashboard.html`: واجهة لوحة التحكم الرئيسية وشاشات النظام ودليل المستخدم الداخلي (<kbd>F1</kbd>).
  - `command-palette.js`: محرك لوحة الأوامر الذكية، خوارزميات المطابقة، الفهرسة اللحظية، والبحث متعدد الكيانات.
  - `dashboard.js`: منطق تشغيل الواجهة، العمليات الفندقية، الحسابات، والفواتير.
  - `main.js`: نقطة الدخول لتطبيق Electron وإدارة النوافذ وقواعد البيانات.
